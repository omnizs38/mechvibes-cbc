A FEW GOOD QUESTIONS

Good to know.

Is 3.0 available to download?

3.0 is in beta development. Download cards show the latest published release available for each platform. An unpublished build is never presented as a download.

Does this change my keyboard?

No hardware changes. The desktop app plays sound in response to global input while it is running. You can mute it or quit whenever you like.

Does the demo record what I type?

No. The preview processes keys only inside its input field, in your browser. Text is not saved or transmitted, and no microphone access is needed.

What about existing soundpacks?

Existing supported soundpacks stay compatible. Profile backups contain settings, not audio files. Install the corresponding soundpacks before applying imported profiles.

Who is behind the project?

Mechvibes-cbc builds on Hai Nguyen’s original MIT-licensed Mechvibes. Fork modifications use MPL-2.0. Explore the repository to contribute or report a problem.
